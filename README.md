### 🌟 Infinity Job Portal

Infinity Job Portal is a modern web-based job recruitment system that bridges the gap between job seekers and employers through an intuitive and efficient platform.

---

### 🔥 Features

* 👤 **User Authentication & Authorization**

  * Secure login/signup for job seekers and recruiters

* 💼 **Job Management**

  * Recruiters can post, update, and delete job listings

* 🔍 **Advanced Job Search**

  * Filter jobs based on role, location, and keywords

* 📄 **Application Tracking**

  * Job seekers can apply and track their applications

* 📊 **Recruiter Dashboard**

  * Manage job posts and view applicants

* ⚡ **Optimized Performance**

  * Fast and responsive UI with efficient backend handling

---

### 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend:** Spring Boot / Node.js (adjust based on your implementation)
* **Database:** MySQL / Oracle SQL / Supabase
* **Authentication:** JWT-based authentication

### ⚙️ Installation & Setup

#### 1. Clone the repository

```bash
git clone https://github.com/your-username/infinity-job-portal.git
cd infinity-job-portal
```

#### 2. Setup Backend

```bash
cd backend
npm install   # or mvn install
npm start     # or mvn spring-boot:run
```

#### 3. Setup Frontend

```bash
cd frontend
npm install
npm start
```

---

### 🔐 Environment Variables

Create a `.env` file in the backend:

```
DB_URL=your_database_url
DB_USER=your_db_user
DB_PASSWORD=your_password
JWT_SECRET=your_secret_key
```
